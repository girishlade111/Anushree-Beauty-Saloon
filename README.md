# Anushree Beauty Saloon

A modern, responsive website for Anushree Beauty Saloon showcasing beauty services, packages, and pricing.

## 🌟 Features

- **Modern & Responsive Design**: Works seamlessly on all devices with enhanced styling
- **Service Showcase**: Complete listing of all beauty services with pricing
- **Special Offers**: Prominent display of current deals
- **Online Booking**: Integration with ladestack.in for appointments
- **Contact Information**: Clear contact details and location information
- **SEO Optimized**: Built with best practices for search engine visibility
- **Enhanced Animations**: Smooth transitions and hover effects
- **Professional Color Scheme**: Elegant gold and cream theme

## 🛠️ Technologies Used

- **React**: JavaScript library for building user interfaces
- **Vite**: Next generation frontend tooling
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **React Router**: Navigation between pages

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/girishlade111/Anushree-Beauty-Saloon.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Anushree-Beauty-Saloon
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

The website will be available at `http://localhost:3000`

### Build

Create a production build:
```bash
npm run build
```
